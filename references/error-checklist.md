# 初中数学 · 题目/答案错误检查清单

对照本清单逐项排查。**注意区分"错误"与"提示"**——只有硬伤才算错误（见 SKILL.md 核心原则）。

---

## 一、题目（题干/题号/图文）错误清单

### 1. 题号系统
- [ ] 重复编号（同一编号出现两次；跨页尤其常见）
- [ ] 跳号 / 缺号
- [ ] 乱序（如 11 之后出现 7）
- [ ] 编号与题型/Part 层级不匹配（题型三重新从 1 编号 vs 全卷连续编号，要看清本卷规则）
- [ ] 选项编号错（A/B 缺失或重复）

### 2. 题干文字
- [ ] 错别字（"笃学数"≠"笃学书"；"列竖式"≠"例竖式"）
- [ ] 漏字 / 多字（典型：`随着x的变化而变的规律` 漏"化"；`变化而变化`）
- [ ] 标点误用（典型：数列的逗号误打成加号 `a1+a2+…a99` 应为 `a1，a2，…，a99`；顿号/分号混淆）
- [ ] 限定词缺失或错误：**正数/正整数/自然数**、非负、至多/至少、不超过/不小于（决定答案范围，配答案一起看）
- [ ] 单位缺失或错误（cm/m、元、度）
- [ ] 变量/字母未定义或前后不一致（前文用 x 后文用 y）
- [ ] 条件自相矛盾（"各数字互不相同"但约束推出相同）

### 3. 图文一致
- [ ] 图中数字与文字数字不一致
- [ ] 图中字母/标注缺失、箭头方向反了（程序框图"是/否"支路！）
- [ ] 文字引用的图号错位（"如图2"实际是图3）
- [ ] 阴影/刻度/框选位置与文字描述不符（典型：日历框选 8,10,16,22,24，图上框必须覆盖这五个位置）
- [ ] 图形本身画错（菱形/三角形标注与题设矛盾）

### 4. 可解性（自己当学生做一遍）
- [ ] 条件不足（少给一个量）→ 存疑，写清缺什么
- [ ] 条件矛盾（无解）→ 存疑/错误
- [ ] 多解：先判断是否题型特征（"所有值""可能是""存在性"）→ 提示；题目明确要求唯一值却多解 → 存疑
- [ ] 答案范围超出所学（初一考了未学知识）→ 提示

### 5. 页结构与版面
- [ ] 整页空白（只有页眉页脚）
- [ ] 题目被截断、选项被拆页
- [ ] 图表与被引用文字跨页过远 / 图丢失
- [ ] 缺"题型六"这类层级标题（从题型五直接跳到题型七）

## 二、答案错误清单（模式B）

### 严重度分级
| 级别 | 类型 | 说明 |
|---|---|---|
| 🔴 | 答案错误 | 最终答案数值/结论错误 |
| 🔴 | 答案不全 | 多解题只写了部分情况（如只给 45² 的情形，漏 54²） |
| 🟡 | 过程错误 | 答案对但中间步骤错（笔误、复制粘贴残留、条件抄错） |
| 🟡 | 方法错误 | 用错知识点但凑对答案 |
| 🟢 | 表述问题 | 漏单位、漏"答"、约分不彻底 |

### 逐项检查
- [ ] 用独立复算核对**每个**空/每问（包括"（1）（2）（3）"小题）
- [ ] 代入回验：把答案代回题干条件（尤其方程、函数、几何长度）
- [ ] 特殊值/极端值检验（x=0、端点、边界日期）
- [ ] 枚举类题目：答案是否是"所有"解（多解漏解重灾区：绝对值、等腰三角形、直角三角形边的分类、概率)
- [ ] 多解题答案写法："23或32"这种形式要接受，别判错
- [ ] 与菁优网原题官方答案比对（见 jyeoo-workflow.md）

## 三、初中高频题型重点核验部位

| 题型 | 重灾区 | 核验配方 |
|---|---|---|
| 程序框图（循环） | 循环停止条件、回代方向、分数输入 | 模拟循环（verify_examples 例1） |
| 数式规律 | 符号交替、分式分母序列、第1项起点 | 写通项代几项验证 |
| 图形规律 | 差值数列（等差/二阶差）、共享边 | 枚举前4项再拟合 |
| 日历/数阵 | 竖列+7、框选形状映射、月中日期边界 | 枚举位置验证选项 |
| 数位与整除 | 位值表示（10a+b）、末尾数、数字和、末三位拆分 | 数字枚举（例2） |
| 新定义符号 | 取整（⌊x⌋/符号[x]）、Σ、阶乘、自定义运算 | 逐项展开算小例子 |
| 新定义数（小明数/笃学数类） | 定义边界、首位不能为0、互异约束 | 全枚举（例2） |
| 集合/新概念 | 互异性、0/1 特殊值、分母不为0 | 枚举（例5） |
| 绝对值/数轴 | 分类讨论漏解、"距离"不带方向 | 分区间检验 |
| 动点/几何存在性 | 等腰/直角的多种情况、斜边未定 | 穷举情形 |
| 勾股定理 | 8,15,17 型：15 也可能是斜边 | 两边比较 |
| 铺地锦/列竖式/格子乘法 | 斜行合并、进位、字母与位值映射 | 先代数化再枚举（见 SKILL 案例） |

## 四、真实案例速记（来自实际校对）

1. **题号错乱**：第6页首题编号"7."——前文已有第7题，且夹在第11与12题之间 → 应改为"12."后续顺延。
2. **标点误用**："99个数a1+a2+…a99" → 应为"a1，a2，…，a99"（逗号误打成加号）。
3. **漏字**："随着x的变化而变的规律" → "随着x的变化而变化的规律"。
4. **多解确认（不是错）**：铺地锦题 b=6 时 a 可为 1、3、5 → 615/645/675 三解齐全即对；列竖式题官方答案就是"23或32"；程序题官方答案就是"10、8/3、2/9"。
5. **答案不唯一=答案问题（要改）**：笃学数题若答案册只写一个数 → 标注"答案不全"，补全 4467、4564、4661。
