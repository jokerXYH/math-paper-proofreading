# 菁优网（jyeoo.com）题源检索与比对流程

目标：为每道待核对题目找到**原题 + 官方答案**，作为独立复算之外的第二证据。

---

## 一、什么时候搜

- 模式B（有答案）：每道"答案与自算不一致"或"多解"的题，必搜。
- 模式A：题干疑似有问题（漏条件、图文不符）的题，搜原题看原版表述。
- 抽样：普通题抽 10~20% 验证卷子整体质量。

## 二、关键词提取（决定命中率）

优选**独特字符串**，越怪越好命中：

1. 自定义名词：`"笃学数"`、`"图新数"`、`"小明数"`、`"奥运和"`、`"新奇数"`、`"新异数"`
2. 罕见数据组合：`"47×51" "2397"`、`"a+b+c+d+e+f+g+h"`
3. 短句原样：`"每增加一个菱形图案"`、`"错误!未定义书签"`（防复制残留）
4. 整句题干：`"现如果有99个数"`、`"第五次输出的结果为1"`

## 三、搜索渠道（按成功率排序）

1. **搜索引擎摘要**（首选，快）：
   - websearch 工具直接查；
   - 备选：360（`https://www.so.com/s?q=...`，对国内教育站收录好）、Bing；百度/搜狗可能出验证码。
   - 搜索词加 `答案` / `解析` / `精品解析`；约 50% 结果摘要里直接带官方答案片段。
2. **菁优网站内**：`site:jyeoo.com 关键词`。题目页常被登录墙拦住，看搜索摘要即可拿到答案行。
3. **镜像站点**（菁优题常被整套试卷复制）：
   - 学科网 zxxk.com、21世纪教育网 21cnjy.com、组卷网 zujuan.xkw.com
   - renrendoc.com / 道客巴巴 / 豆丁 / Scribd（搜"精品解析"+关键词）
4. **开源工具**（批量场景）：jyeoo-paper-formatter（组卷页面提取，无需会员，克隆到 `references/github/` 即可用）等，见 toolchain.md 第六节。

## 四、比对规则（防止被带偏）

| 情况 | 处理 |
|---|---|
| 官方答案与自算一致 | ✅ 通过，记录来源 |
| 官方答案是"x或y"多值 | 正常！多解=设计特征；自算多值齐全即通过 |
| 官方与自算不一致 | 做第三次验算；仍不一致 → 🟠存疑，报告里并列两种答案与出处 |
| 找到多份来源互相矛盾 | 以自算+逻辑复核为准，存疑并列出分歧 |
| 完全找不到原题 | 依靠自算+程序验证，结论中注明"未找到原题" |

**注意**：菁优网的"试题解析"是用户/老师上传的，不是官方发布，也可能错；按上表处理。

## 五、记录格式

```
题20 原题出处：2025-2026学年福建省福州十九中七年级（下）月考（Scribd转载）
官方答案：15×41=615（原卷）；复核自算：615/645/675 均满足图示 → 判"答案不全"
```

报告"依据"列写法：`原题（可注明试卷名）+ 独立复算/程序枚举`。
