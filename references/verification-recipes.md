# 题型核验配方（初三到初一通用，附代码模板）

核验顺序：**① 手推一遍 → ② 程序验证（可编程题）→ ③ 原题比对 → ④ 三方取交集下结论**。

代码模板直接复制 `scripts/verify_examples.py` 里对应函数改数据。

## 关键细节经验

### 1. 程序框图题
- 先写出"单步函数"再套循环，不要肉眼数次数。
- 注意停止条件是 `>` 还是 `≥`（决定边界值被输出还是回代）。
- 输出反推输入：从输出值**逆向解方程**可能产生分数解，一天不落地枚举验证（正数≠正整数！）。
- 计数"第几次输出"时，输入本身不算输出。

### 2. 枚举题的规模控制
- 4 位数字枚举 ≈ 10^4 组合，秒出；7 位以上再考虑剪枝。
- 约束多时把所有约束写进 `for` 循环里的 `continue` 条件，避免漏检。
- 互异数字：`len({a,b,c,d}) < 4: continue`。

### 3. 周期题
- 用 `seen` 字典记录第一次出现位置：`周期 = 总长 - 首次出现位置`，区分"预周期 + 周期"。
- 第 n 项定位：`n <= 预周期长度 → 直接取；否则 (n-1-预长) % 周期 + 预长`。

### 4. "多解"的判定口径
- 题目问"所有值/可能是/哪些" → 多解是**考点**，答案必须写全（写全=正确；只写一个=答案不全🔴）。
- 题目默认唯一（填空题）却多解 → 先怀疑自己；复算+原题比对后再决定是否"存疑🟠"。
- 官方答案含"或"字的题目 → 多解=标准做法，别判错。

### 5. 几何/分类讨论
- 穷举情形清单（腰/底、直角边/斜边、在线段/延长线）后逐个解。
- 面积法/勾股定理核对：`c² = a²+b²`、`斜边×高 = 两直角边积`。
- 结果必须满足非负长度、三角形不等式。

### 6. 与原题比对
- 数值答案：原题官方答案优先；与自算不一致时第三次验算，仍冲突则标"存疑"并展示两种推导。
- 不要迷信原题：原题也可能印刷错，但判"原题错"需要更强的证据（多来源一致才行）。
